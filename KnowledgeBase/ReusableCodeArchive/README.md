# Conditional reusable code archive

No active Category B implementation candidate is currently approved here.
Previously stored Assist and legacy runtime code contained Lab-specific defaults,
scene names, validation rules, or duplicated responsibilities already owned by
the validated Common package, so it was moved to the restricted legacy archive.

Use `UnityProject/LocalPackages/com.emvr.lab-common/` for validated shared
behavior. A future Category B candidate may be added only after an independent
minimal validation proves that it contains no target formula, answer, object ID,
step order, scene wiring, domain-specific default, or duplicate Common/XRI
responsibility.
