# Restricted legacy Lab-specific summaries

This archive preserves original pre-workflow summaries for audit and deliberate
comparison only. Files here may expose old Lab implementation, exact
coordinates, class names, object IDs, scene wiring, formulas/answers, and other
details that would invalidate a blind rebuild evaluation.

The Builder Agent must not read, search, summarize, or cite this directory
during a blind rebuild. It is not Category C background context, not Gate 0
input, and not an approved code source. Access requires an explicit user request
that names an exact file and states a non-blind comparison purpose; permission
for one file does not authorize its siblings or the directory as a whole.

Reusable construction experience extracted from these materials belongs only
in `KnowledgeBase/rebuild-lessons/build-experience/` after removal of Lab-specific
answers, identifiers, coordinates, wiring, and copied code.
