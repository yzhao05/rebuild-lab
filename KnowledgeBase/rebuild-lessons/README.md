# Rebuild lessons

This directory has two sources of normalized, safe construction experience:

- `build-experience/pre-workflow/`: curated cross-Lab lessons migrated from
  rebuilds and minimal validations completed before the Gate workflow existed;
- `<lab_id>.md`: one verified reusable lesson generated by Gate 10 of a current
  workflow run.

The original pre-workflow summaries are separated under
`KnowledgeBase/legacy-lab-specific-summaries/`. They may contain old Lab
implementation, coordinates, class names, object IDs, scene wiring, and
answers. They are restricted and are never a Gate 0 input. Only the normalized,
cross-Lab safeguards in this directory are recommended mandatory context.

Lesson files contain recurring error signatures, ownership, allowed fix
locations, verified initial-value/API/lifecycle constraints, and prevention
checks. They must not
contain Gold Reference details, target answers, Lab-specific rubric logic,
secrets, or unverified guesses.

At Gate 0 of every later rebuild, review every lesson file in this directory
and complete `LabSpecs/<lab_id>/prior-lessons-review.md`. A lesson may guide
prevention and debugging, but it does not become a target-Lab requirement.
