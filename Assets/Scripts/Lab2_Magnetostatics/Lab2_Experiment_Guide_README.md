# Lab 2 Magnetostatics 实验操作 README

本文说明如何在 Unity/VR 场景中完成 Lab 2 Magnetostatics 静磁场实验。

## 1. 打开实验场景

如果场景还没有生成，先在 Unity 顶部菜单执行：

```text
Tools > Magnetostatics Lab > Build Lab 2 Scene
```

生成后打开：

```text
Assets/Scenes/Lab2_Magnetostatics.unity
```

进入 Play Mode 后，在 Game 视图中进行实验。

## 2. 场景区域说明

- 左侧 `Current loader`：电流加载区，用于给导线或线圈设置电流方向和强度。
- 中间透明区域：磁场可视化区域，只有放入该区域的电流源会主要参与观察。
- 右侧电流源架：提供可拖动的直导线和螺旋线圈/solenoid。
- 下方 `1-5` 按钮：加载 Lab 2 的五个练习场景。
- 下方控制按钮：
  - `C`：清空预设电流源。
  - `F`：显示/隐藏磁场线。
  - `V`：显示/隐藏方向采样。
  - `X`：翻转当前可视化区域内电流方向。
  - `+ / -`：增大或减小当前可视化区域内电流强度。

## 3. 桌面测试操作

没有 VR 头显时，可以用鼠标模拟 VR 手柄：

1. 移动鼠标，黄色射线表示指针方向。
2. 鼠标指向直导线或线圈。
3. 按住鼠标左键拖动物体。
4. 拖动物体穿过左侧红/蓝电流加载条，设置电流。
5. 红色表示 `+I`，蓝色表示 `-I`。
6. 颜色越深，电流强度越大，共 6 档。
7. 按住 `R` 并拖动鼠标，可以旋转电流源。
8. 将带电流的导线或线圈放入透明可视化区域，观察磁场线变化。

## 4. VR 操作

1. 使用手柄射线或直接触碰选择按钮。
2. 使用 Grip/Select 抓取直导线或线圈。
3. 将电流源移动到红/蓝 current loader 设置电流。
4. 将电流源放入透明可视化区域。
5. 观察闭合磁场线和多个电流源叠加后的磁场结构。
6. 悬停或选中对象时，会显示对象说明标签。

## 5. 推荐实验流程

### Step 1：观察单根直导线

1. 点击 `C` 清空场景。
2. 从右侧拖一根直导线。
3. 将它拖过红色或蓝色 current loader。
4. 放入可视化区域。
5. 观察磁场线是否围绕导线形成闭合环。
6. 使用不同颜色/深浅的 loader，比较电流方向和强度对磁场线的影响。

### Step 2：观察单个螺旋线圈

1. 点击 `C` 清空场景。
2. 从右侧拖一个 solenoid。
3. 设置红色或蓝色电流。
4. 放入可视化区域。
5. 观察线圈内部和外部磁场线的闭合结构。

### Step 3：观察叠加效应

1. 放入两个或多个电流源。
2. 改变它们的方向、位置、角度和电流强度。
3. 观察磁场线在某些区域加强或抵消。
4. 使用 `X` 快速翻转方向，比较翻转前后的磁场图案。

## 6. 练习题对应操作

### Scene 1：Q1-Q2

点击 `1` 加载 Scene 1。

需要完成：

- 判断场景中有哪些电流源。
- 判断两个电流源电流方向是相同还是相反。
- 判断电流强度是否相同。
- 截图记录复现场景。
- 使用 `X` 或手动改变一个电流源方向，完成 Q2 截图。

### Scene 2：Q3

点击 `2` 加载 Scene 2。

需要完成：

- 比较直导线和线圈组合产生的磁场图案。
- 判断电流源类型、方向和相对强度。
- 尝试手动调整位置和电流强度，复现文档中的 top-down 场景。
- 截图并在报告中说明差异。

### Scene 3：Q4

点击 `3` 加载 Scene 3。

需要完成：

- 观察三根直导线的磁场线分布。
- 判断三根导线的电流方向关系。
- 判断哪一根电流更强或更弱。
- 尝试重新摆放三根导线并截图。

### Scene 4：Q5

点击 `4` 加载 Scene 4。

需要完成：

- 观察两个线圈同向电流时的磁场。
- 使用 `X` 或手动设置，让两个线圈电流反向。
- 使用 `+ / -` 或 current loader 改变强度。
- 比较同向、反向、强弱不同情况下的磁场线变化。
- 截图支持你的解释。

### Scene 5：Q6

点击 `5` 加载 Scene 5。

需要完成：

- 观察两个线圈形成的 Helmholtz-like 磁场。
- 重点观察红色 ROI 区域内的磁场线是否更接近平行、均匀。
- 调整两个线圈距离、方向和强度，尝试更好地近似目标图案。
- 截图并说明为什么该结构接近 Helmholtz coil。

- 是否需要更多电流源类型，例如电流片、单个电流环、可变长度 solenoid？
- 是否需要更自由的观察视角，例如俯视、进入线圈内部、从下方观察？

## 7. 截图建议

每个练习建议至少保存：

- 一张正面 Game 视图截图。
- 一张俯视或接近 top-down 的截图。
- 一张改变电流方向或强度后的对比截图。

截图时尽量让以下内容可见：

- 电流源位置。
- 电流源颜色和深浅。
- 磁场线形状。
- 目标 ROI 区域。

## 8. 常见问题

### 字体看不清

确认当前场景中存在 `Lab 2 Controller`，并且其上有 `MagneticScenePresentation` 组件。进入 Play Mode 后，该组件会自动使用 Lab 1 已验证的字体清晰化方案。

### 没有磁场线

检查：

- 电流源是否已经通过 current loader 设置了非零电流。
- 电流源是否放入透明可视化区域附近。
- `F` 是否被关闭了。

### 鼠标拖不到物体

检查：

- 是否在 Game 视图中操作。
- 鼠标左键是否按住。
- 物体是否是右侧的直导线或 solenoid，而不是说明板或装饰物。

### 修改后场景没有变化

重新执行：

```text
Tools > Magnetostatics Lab > Build Lab 2 Scene
```

然后重新进入 Play Mode。
